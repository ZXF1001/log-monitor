# 日志查看器

个人使用的只读日志查看器。Python 后端同时提供网页和 API，只需启动一个服务，不需要 Node.js、数据库或前端构建。

支持 Windows 开发和 Linux 运行，使用 uv 管理 Python 环境与依赖。

## 快速启动

在项目目录执行：

```sh
uv sync --locked
uv run python app.py
```

浏览器打开 **http://127.0.0.1:8000**，点击左侧“添加日志”，填写名称和日志文件的**绝对路径**。文件需要已经存在，且运行服务的用户有读取权限。日志内容仅供查看，网页不能修改日志文件。

项目默认使用 Python 3.13，uv 会按照 `.python-version` 选择解释器。代码支持 Python 3.12 及以上。依赖版本已从 PyPI 核实并锁定在 `pyproject.toml` 和 `uv.lock`；提交和部署时保留锁文件。

修改地址、端口或配置文件：

```sh
uv run python app.py --host 127.0.0.1 --port 8080 --config config.local.json
```

使用自定义配置前，先创建它，例如复制 `config.json`。也可以通过 `LOG_MONITOR_CONFIG` 环境变量指定配置；命令行 `--config` 优先。

## 配置日志

默认配置文件是项目目录里的 `config.json`：

```json
{
  "logs": [
    {
      "name": "应用日志",
      "path": "/var/log/myapp/app.log"
    },
    {
      "name": "Nginx 访问日志",
      "path": "/var/log/nginx/access.log"
    }
  ]
}
```

Windows 路径建议使用正斜杠，例如 `C:/logs/app.log`，避免 JSON 反斜杠转义问题。中文名称和路径均可使用。

- 网页添加的路径会保存到当前配置文件。
- 手动修改配置后，侧边栏约 5 秒内自动更新，无需重启。可以直接改名称、增加或移除条目。
- 配置格式错误时，页面提示错误并保留上一份有效列表；修正后自动恢复。错误期间禁止从网页写回，避免覆盖未完成的配置。
- 配置里暂时不存在或不可读的文件仍会显示，选中时提示原因；文件恢复后可以重试。
- 配置目录需要可写，才能从网页添加日志。后端以临时文件加原子替换方式保存配置。

## 查看方式

- 首次显示文件末尾最多 256 KiB，点击“加载更早”向前分页。
- 自动刷新每 2 秒增量读取新内容；手动刷新也只读取新增内容。“回到最新”会重新读取文件尾部。
- 关闭自动刷新可暂停读取；“跟随底部”控制追加内容时的滚动。向上阅读时不会强行拉回底部。
- 浏览器最多保留约 100 万字符。跟踪时丢弃最早内容；加载历史达到上限后暂停自动刷新，回到最新即可继续跟踪。
- 支持日志清空、截断和轮转；文件被替换时自动重新读取。
- 按 UTF-8 解码，损坏字节以替代字符显示；末尾尚未写完的 UTF-8 字符会等待后续字节。GBK 等其他编码需要先转换为 UTF-8。

## 放到 Linux

复制项目源码、`pyproject.toml`、`uv.lock` 和 `.python-version`，**不复制 Windows 的 `.venv`**。在 Linux 项目目录执行：

```sh
uv sync --locked --no-dev
uv run --no-dev python app.py
```

把配置里的路径改成 Linux 上的真实路径，并用有日志读取权限的普通用户运行。

默认仅监听服务器本机。可以在自己电脑上建立 SSH 转发后，访问 http://127.0.0.1:8000：

```sh
ssh -N -L 8000:127.0.0.1:8000 YOUR_USER@YOUR_SERVER
```

需要局域网直接访问时，用 `--host 0.0.0.0` 启动，并通过 `http://服务器IP:8000` 打开。此工具不包含登录功能，任何能访问它的人都能查看已配置日志和添加可读路径，适合限制在自己的可信网络内使用。

## 开发验证

```sh
uv sync --locked
uv run pytest -q
```

测试使用临时文件，不读取真实业务日志。覆盖配置热更新、坏配置回退、路径校验、增量读取、UTF-8 字符边界、大文件分页、截断和轮转。Windows 不运行 POSIX 文件权限测试。
